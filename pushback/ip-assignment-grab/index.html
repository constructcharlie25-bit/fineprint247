Why this clause is risky

Many contracts say the client owns all work product. That is fine for the deliverable itself. The grab is when it also covers anything you made before this project or reuse across clients: your code libraries, templates, processes.

Sign it as written and you have handed over your toolkit. The fix is one sentence: carve out pre-existing IP so the client owns the project deliverables and gets a license to your reusable materials, while everything else stays yours.

The pushback email

Copy this, fill in the brackets, send it.

Subject: One tweak on the IP section

Hi [Client name],

Happy for you to own everything I build specifically for this project. But as written, the IP section also covers tools and templates I built before this engagement and reuse across clients. That is my toolkit.

Can we carve out pre-existing IP? You get full ownership of the project deliverables, plus a license to use my reusable materials as part of them. Everything else stays mine.

Thanks,
[Your name]
